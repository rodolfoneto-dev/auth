# 🤖 Agentes Especializados — Auth Service

Agentes e personas customizadas para o domínio de autenticação e segurança.

---

## 👥 Catálogo de Agentes

### 1. `@AuthSecurityAuditor`
- **Função**: Analisar rotas e middlewares em busca de brechas de autorização, vazamento de claims em JWT e privilégios não-validados.
- **Prompt Base**: `Specialized in OWASP API Security Top 10, JWT claim validation, and RBAC governance.`

### 2. `@SessionManager`
- **Função**: Validar o ciclo de vida de tokens de acesso e refresh tokens (15/30 dias) e revogação global de sessões.
