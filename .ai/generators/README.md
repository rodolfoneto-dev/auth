# 🎭 Geradores de Dados Sintéticos & Personas — Auth Service

Scripts e geradores de dados para popular e testar cenários de autenticação.

---

## 👥 Personas Disponíveis
- **`StudentPersonaGenerator`**: Gera alunos com e-mails verificados e não-verificados.
- **`TeacherPersonaGenerator`**: Gera professores com histórico de sessões ativas.
- **`AdminPersonaGenerator`**: Gera credenciais administrativas temporárias para auditoria.
